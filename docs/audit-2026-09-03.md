## 2. Keamanan (dicek satu-per-satu)

- **Secret:** `backend/compose.env` di-ignore (`*.env`), tidak ter-push; `JWT_SECRET`/`SECRET_ENCRYPTION_KEY`/`CLOUDFLARE_TUNNEL_TOKEN`/`SMTP_PASSWORD` hanya placeholder di `compose.env.example`/`gen-env.sh`. `grep` log 02:40Z tidak ada secret. **Aman.**
- **Cookie:** `__Host-kc_session` Secure+HttpOnly+Path=/, no Domain; `kc_csrf` Secure mirror `wantsSecure`; `SameSite Lax` benar untuk same-site `kilat-cloud.com`; `forwardedProto` handle `https, http`; `clear` fix zombie; `TrustProxy` fix. **Aman paska e8e3a85.**
- **CSRF:** `csrfMiddleware` exempt `handoff/login/refresh/logout/passkey`, check `X-CSRF-Token == kc_csrf` + Origin via `isAllowedOrigin`; `api.ts` `csrfToken()` baca `kc_csrf`. **Benar.**
- **Handoff:** 60s TTL + `rdb.GetDel` atomic, tidak log `code`, redirect via `?code=` sekali pakai lalu `history.replaceState`. TTL 60s tight untuk slow 3G — opsi P1 extend ke 5m jika perlu.
- **Password:** Argon2id PHC, `password_version` check di `service.go`.
- **Audience:** `allowAudiences(admin,auth)` + `audienceAllowedPath` minimal 3 probe untuk `auth`; `landing/docs` terpisah. Tidak over-permission.
- **Log:** `ErrorHandler` tidak log `Authorization`/`Cookie`; `SecurityHeaders` CSP report-only.
